## v3.5.0 - 2026-10-22

### Features
- Arbiter now includes a working member-directory API for approved Even Legion tools. It provides current division memberships, merit totals, and merit ranks for individual members or filtered groups, while read-only access controls and usage limits protect Arbiter from unauthorized or excessive use. by @Spacesai1or in [#109](https://github.com/EvenLegion/Arbiter/pull/109)
- Arbiter now includes a staff website for managing which approved tools can use the member-directory API. Authorized staff can sign in with Discord, register integrations, create or replace access keys, review their status, and revoke access when it is no longer needed. by @Spacesai1or in [#110](https://github.com/EvenLegion/Arbiter/pull/110)
- Integrators can now browse and download a complete reference for Arbiter's supported v1 API, including sign-in and credential requirements, request and response shapes, stable errors, pagination, and rate limits. The published reference stays aligned with supported API behavior as Arbiter adds new capabilities. by @Spacesai1or in [#115](https://github.com/EvenLegion/Arbiter/pull/115)
- Event organizers now choose an expected duration when creating an event, from one to three hours in half-hour steps. Arbiter preselects merit for members who attend at least half of the event's actual duration when less than expected duration, or half of the expected duration when longer than expected. Event runners can still adjust merit selections before submitting. by @Spacesai1or in [#118](https://github.com/EvenLegion/Arbiter/pull/118)
