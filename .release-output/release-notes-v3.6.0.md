### Features
- Staff can now preview a nickname sync before running it. The new dry run option on /staff sync_nickname lists every nickname a real sync would change, including names someone edited by hand, and every staff member it would skip, without changing anyone's nickname. by @Spacesai1or in [#130](https://github.com/EvenLegion/Arbiter/pull/130)

Any old number is removed the next time a member's nickname updates, and names get two more characters of room. by @Spacesai1or in [#133](https://github.com/EvenLegion/Arbiter/pull/133)
